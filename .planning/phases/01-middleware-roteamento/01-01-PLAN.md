# Plan 01-01: Middleware condicional para 44x.site

## Objective

Modificar o middleware para que plataformas marcadas como `casino_only` tenham acesso publico a `/` e `/home` (sem redirecionamento para `/login`), e tenham rotas de loteria bloqueadas (redirect para `/home`).

## must_haves

- Acesso sem login a `/` e `/home` no dominio 44x.site
- Rotas de loteria retornam redirect para `/home` no 44x.site
- Nenhuma outra banca e afetada
- Usuarios logados continuam navegando normalmente
